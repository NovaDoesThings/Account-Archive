# 🗃️ Account Archive

**Account Archive** is a database dedicated to archiving information about Gorilla Tag player accounts. It organizes player records to make stored account information easier to browse, identify, and maintain.

## 📋 Stored Information

Each archived player record may contain the following information:

| Field | Description |
|---|---|
| **ID** | The player's unique account identifier. |
| **Name** | The player's recorded username. |
| **Color** | The player's recorded in-game color. |
| **Last Seen Date** | The most recent date the player was observed. |

## 🎯 Purpose

The goal of Account Archive is to maintain an organized collection of Gorilla Tag player records, allowing information to be stored and referenced over time.

## 📁 Repository Structure

Player records are organized within the repository. Each account's stored information can be used to identify the corresponding record and review its available details.
